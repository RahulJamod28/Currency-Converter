# 💱 Currency Converter (Fetch API Project)

A Simple And Beginner-Friendly **Currency Converter** Web Application Built Using  
**HTML, CSS, and JavaScript**.  
This project uses the **Fetch API** to fetch real-time currency exchange rates.

---

## 🚀 Features
- Convert Currency from one country to another
- Uses Fetch API for live exchange rates
- Country flags update automatically
- Clean and simple UI
- Perfect for JavaScript practice

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Fetch API)
- Font Awesome (icons)
